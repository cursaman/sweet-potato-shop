# 온기담은 고구마

결제 기능 없이 상품을 소개하고 주문 문의 문장을 만드는 독립형 정적 페이지입니다.

## 사용 방법

`index.html`을 브라우저에서 열면 바로 확인할 수 있습니다. 서버나 설치 과정이 필요하지 않습니다.

실제 판매를 시작하기 전에는 `index.html`의 다음 내용을 판매 정보에 맞게 바꿔 주세요.

- 브랜드명과 상품 설명
- 실제 판매 가능한 크기와 수량
- 판매자 정보와 연락처
- 가격, 배송비, 교환·환불 안내

현재 주문 기능은 선택한 내용을 클립보드에 복사하는 방식이며 결제나 주문 저장은 하지 않습니다.
